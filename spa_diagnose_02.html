Same-Origin Library Test

Tests whether SharePoint allows loading JS files from the same Document Library.

Setup — upload these files to the same Document Library folder:
libs/chart.js — download from https://cdn.jsdelivr.net/npm/chart.js@4/dist/chart.umd.min.js
libs/apexcharts.js — download from https://cdn.jsdelivr.net/npm/apexcharts@3/dist/apexcharts.min.js
libs/test-helper.js — a tiny file you create (see below)
same-origin-test.html — this file

Create libs/test-helper.js with this content:
window.__SP_SAME_ORIGIN_OK = true;
